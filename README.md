Rust Web Crawler An asynchronous web crawler built from scratch in Rust. This project demonstrates high-performance network I/O, concurrent batch processing, and safe state management. It traverses web pages, parses HTML DOM trees to extract links, and normalizes URLs, all while leveraging Rust's memory safety and zero-cost abstractions.
